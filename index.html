Unraid Dash support

Last updated October 22, 2026.

Unraid Dash is a native client for your own Unraid 7.2 or later server on Mac, iPhone and iPad. It requires macOS 26 or later or iOS/iPadOS 26 or later. Your device must be able to reach your server, and server management features require the corresponding API permissions.

Try the app without a server

Choose Try with demo data on the welcome screen. If you have already added a server, turn on Show demo server in Settings and select Tower, the demo server. The demo uses sample data and does not connect to a real server.

Connection help

  • Cannot reach the server: join the server's local network or enable your separately configured Tailscale connection. Check the server address and open Diagnostics in Settings to see route results.
  • Local network access: allow Unraid Dash's Local Network permission in your device's privacy settings when connecting over the LAN.
  • API unavailable: check Unraid's Settings → Management Access → Unraid API Status and confirm the server runs Unraid 7.2 or later.
  • Tailscale route unavailable: confirm your device and server are reachable through Tailscale and that the Unraid Tailscale plugin's Unraid services listen on Tailscale IP setting is enabled.
  • Waiting for iCloud Keychain: confirm iCloud Keychain is available for your Apple account and allow time for credentials to sync. Use Paste API key or Reconnect if needed.
  • An action is not permitted: check that the API key grants the relevant operation. A Viewer key supports monitoring; management requires additional permissions. A full-admin key is unnecessary.
  • A web UI stops signing in: check its saved login and Fill and sign in setting. A failed automatic sign-in changes the saved login to fill-only; correct the login before enabling it again.
  • A certificate warning appears: verify the server and certificate independently before trusting a new or changed certificate. Use HTTPS with certificate verification or your trusted Tailscale connection on networks you do not trust.

Saved information

Saved logins can be edited or removed in Settings. Sign out of all web UIs clears website data for a server. Clearing a host's data signs out web UIs on that host across ports. Deleting a server requests removal of its app profile, saved credentials, cached snapshot, certificate pins and web data; it does not revoke API keys or remove content from the server itself.

See the privacy policy for local storage, iCloud sync, icon downloads and information you may choose to share.

Report a problem

Email sequoyahgeber@gmail.com. Include your device model, operating-system version, app version/build, Unraid version, the steps that caused the problem and what you expected. Say whether it also happens with demo data. Screenshots or Diagnostics → Copy logs can help if you choose to include them. Copying logs does not send them automatically.

Review reports before sending. Do not include API keys, passwords, full server addresses, private web UI content or other personal information. There is no need to provide access to your server to file a report.
